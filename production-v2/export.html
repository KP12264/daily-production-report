How the numbers are calculated

  • Adjusted Plan = the saved Daily Plan (same value as Production Entry).
  • Actual = Production Entry cells that exist in that day's plan. Old / renamed keys are listed separately as Unplanned / stale and are not counted.
  • Achievement = total Actual ÷ total Adjusted Plan (daily percentages are never added). Blank when there is no plan.
  • Loss = Pallet Change (Daily Plan) + Manual Loss, shown as Loss excl. Material and Material separately. These are event-minute sums: overlapping events are not merged, so overlapping time can be counted twice (overlaps are flagged in the file).
  • The file states whether the data is complete. When any Line × Shift × Date has NO PLAN, NO ENTRY or ACTUAL WITHOUT PLAN, the totals are marked not fully verified.
  • Production Date is the date saved with the data: a Night shift after midnight stays on its Production Date.
  • Missing data is shown as NO PLAN / NO ENTRY, never as 0. Scrap and Quality are not included (no source in Production V2).
